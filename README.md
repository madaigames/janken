# 忍者の里 じゃんけん

公開ページ: https://madaigames.github.io/janken/

## あそびかた

- 開始前に「あなたの名前」を1つ入力できます。名前はこのブラウザに保存され、オンラインではホストがP1、招待参加者がP2になります。
- 「忍者と対戦」はNPC戦、「ふたりで対戦」は同じ画面での対戦です。
- オンライン対戦では、部屋を作った人がP1、招待コードから入った人がP2です。部屋を作って招待リンクを送り、相手が参加したら手を選びます。
- 自分の操作する手に「あなたのて」、相手の手に「あいてのて」と表示します。
- 先に3勝した方が総合勝利です。引き分けは勝ち数に入らず、3勝が決まるまで回戦が続きます。
- 両方が手を選ぶまでは選択画面のままで、入力した手を変更できます。相手の手は勝敗判定まで隠れ、オンライン対戦では自分の手だけ自分の画面に表示されます。
- スコアリセットは3勝が決まり、対戦が終了した後に表示されます。
- BGMは凩.mp3を15%の音量でループ再生します。ブラウザが自動再生を制限する場合は、最初に画面をタップまたはクリックすると始まります。

GitHub Pagesは `main` ブランチのルートから配信しています。オンライン対戦の接続にはPeerJS Cloudを使い、ゲームの手はブラウザ間のWebRTC接続で同期します。インターネット接続が必要です。
