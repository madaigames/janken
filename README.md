# 忍者の里 じゃんけん

`index.html` を GitHub リポジトリの一番上に置くと、GitHub Pages で公開できる構成です。

## GitHub Pages で公開する

1. GitHubで新しいリポジトリを作ります。
2. このフォルダの `index.html` をリポジトリの一番上にアップロードして保存します。
3. リポジトリの **Settings → Pages** を開き、公開元を **Deploy from a branch**、ブランチを **main**、フォルダを **/(root)** にして保存します。
4. Pages の公開URLを開き、**部屋コードで招待 → 部屋を作る** から招待リンクをコピーします。

同じ公開URLを開いた友だちは、招待リンクまたは部屋コードで参加できます。通信にはPeerJSの共有シグナルサーバーを利用し、対戦データはブラウザ間のWebRTC接続で送ります。ネットワーク環境によっては接続できない場合があります。

このページは外部のPeerJS CDNとPeerJS Cloudを使うため、オンライン対戦にはインターネット接続が必要です。ローカルの `file://` で開く場合はブラウザ制限で通信できないことがあるので、GitHub PagesのHTTPS公開URLで遊んでください。
